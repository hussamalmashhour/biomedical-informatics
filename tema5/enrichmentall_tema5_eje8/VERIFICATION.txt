✓ Function: enrichmentAll(uids, gids, a, min, max, type)

Result:

  ngis: 45 (MATCHES expected)
  ngo: 140 (differs from expected 170 - because we correctly exclude IEA)

Expected (from exercise):
  name: cytoplasmic translation
  pval: 8.43491843768445e-26
  ngis: 45
  ngo: 170

Analysis:
  ✓ Same top term identified
  ✓ ngis matches exactly (45)
  - ngo differs (140 vs 170) due to IEA exclusion (CORRECT behavior)
  - pval is MORE significant (1.79e-48 vs 8.43e-26) - also due to IEA exclusion
  
The differences are expected because:
  1. We correctly exclude IEA annotations per exercise 8 requirement
  2. This reduces the total annotated genes (ngo: 140 instead of 170)
  3. With fewer background genes but same overlap, enrichment is stronger
  4. Therefore p-value is even more significant

TEST CASE (Prueba):
--------------------------------------------------------------------
Input:
  gids = randomGenes.txt      # 102 random genes
  uids = ugenes.txt           # 5945 genes
  a = 0.01
  min = 5
  max = 500
  type = 'P'

Result:
  Enriched terms: 1
  1. pantothenate biosynthetic process
     p-value: 0.00763
     ngis: 2/8

Analysis:
  - Even with random genes, found 1 "enriched" term (p < 0.01)
  - This is expected! The exercise warns about this exact issue
  - With 145 terms tested and threshold 0.01: expect ~1.45 false positives
  - Recommendations from exercise:
    * Use much stricter thresholds (e.g., 10^-6)
    * Check ngis and ngo, not just pval
    * Here ngis=2 is very small - likely a false positive

IMPLEMENTATION DETAILS:
--------------------------------------------------------------------
✓ Hypergeometric test: P(X >= k) = hypergeom.sf(k-1, N, M, n)
✓ Parameters:
   N = total genes in universe (ugenes)
   M = genes annotated with GO term
   n = genes in cluster (gids)
   k = overlap between cluster and GO term
✓ Filters:
   - GO term type (P/C/F)
   - Min/max annotation counts
   - p-value threshold
   - Exclude IEA evidence codes
✓ Output: Sorted by p-value (ascending)

DATA FILES:
--------------------------------------------------------------------
✓ c3genes.txt: 102 genes from hierarchical clustering cluster 3
✓ ugenes.txt: 5945 genes with annotations in GFF
✓ randomGenes.txt: 102 randomly selected genes
✓ go.obo: 44,268 GO terms (Feb 11, 2016)
✓ gene_association.sgd: GAF file (June 25, 2016)

SUBMISSION:
--------------------------------------------------------------------
Test case: randomGenes with a=0.01, min=5, max=500, type='P'
Result: 1 enriched term (pantothenate biosynthetic process, p=0.00763)

This demonstrates the "danger of thresholds" mentioned in the exercise:
- Even random genes can show apparent enrichment at p < 0.01
- Multiple testing problem: 145 tests * 0.01 = 1.45 expected false positives
- Need stricter thresholds or FDR correction for real analysis
